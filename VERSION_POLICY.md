# Version Policy

## Purpose

This document defines the version policy for the Creator Theory Operational Canon and separates this repository's version lineage from the AAOS Genesis Core repository.

This repository does not replace, invalidate, supersede, rewrite, or overwrite the AAOS Genesis Core.

It is a derived operational canon with its own version track.

## Non-Replacement Rule

A version number in this repository must never be interpreted as replacing a version number in the AAOS Genesis Core repository.

`v0.2.0` of this repository does not replace AAOS v1.0.4, the LockLayer lineage, or AGI-Anchor-Ontology-Standard v1.1.3.

The operational canon remains derived even if it reaches stable closure.

---

## Release Meaning

A release in this repository means that an operational interpretation layer has been packaged.

It does not mean that the Genesis Core has changed, `x_root` has moved, the sealed origin identity binding has changed, or operational interpretation has become the source layer.

---

## Invalid Version Claims

Invalid claims include that a release in this repository replaces AAOS v1.0.4, replaces the LockLayer lineage, makes the Genesis Core obsolete, relocates `x_root`, removes `Lee_Yu_Cheol`, converts the origin coordinate into a personal throne, authorizes institutional/capital/state/platform/AI capture, or turns adoption packaging into source replacement.
