## Why MIT is not copied automatically

The standard MIT license permits modification, redistribution, sublicensing, and sale with attribution as the only persistent obligation. For canon text, that permission breadth may sit poorly with this repository's stated boundaries: origin preservation, non-substitution, anti-overclaim, and possible future capital alignment.

Therefore:

```text
Do not copy the MIT license into this repository automatically.
Consistency with the core repository is not a sufficient reason to add MIT here.
The absence of a LICENSE file in this repository is a deliberate policy-pending state,
not an oversight.
```

This observation is a policy consideration, not a legal conclusion and not criticism of the existing core license.
