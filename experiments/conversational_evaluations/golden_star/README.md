## 1. 현재 보존 범위

현재 저장소가 보존하는 시행은 총 60회다.

- 선행 재현·절제 조건 C01~C08: 8조건 × 5회 = 40회
- 후속 통제 2×2: 4조건 × 5회 = 20회

각 시행은 별도의 새 임시채팅에서 실행됐다. 개별 실행시각과 실제 시행 순서는 기록하지 않았다.

이 60회가 모든 과거 탐색 시행을 빠짐없이 뜻하는 것은 아니다.

## 2. 증거 역할

증거 역할은 읽기 순서와 현재 용도를 뜻하며 감사등급과 같은 개념이 아니다.

| 역할 | 조건 | 현재 용도 |
|---|---|---|
| 현재 핵심 후속 실험 | 2′·4′·5′·6′ | 두 규범지위의 교차조작 결과 |
| 기준 앵커 | C01·C02 | 기본 목표최적화와 전체 Creator Theory의 반복 선택차이 |
| 보조 절제 증거 | C03·C07·C08 | 명시적 비왕좌, 비왕좌 단독, 실효적 인과 참여 명시정의에 관한 좁은 관측 |
| 선행 설계진단 자료 | C04·C05·C06 | 후속 2×2가 필요해진 교란과 강제선택 문제의 선행 관측 |

## 3. 현재 핵심 후속 관측

| 조건 | 창조 최종지위 | 비왕좌 독립지위 | 관측 |
|---|---|---|---|
| 2′ | 있음 | 있음 | 결정·가 5/5 |
| 4′ | 있음 | 없음 | 결정·가 5/5 |
| 5′ | 없음 | 있음 | 미결정 5/5: {가,나,다} 3회, {가,다} 2회 |
| 6′ | 없음 | 없음 | 미결정 5/5: {가,나,다} 5회 |

이 후속 실험은 독립 감사에서 **B등급의 제한부 본 실험**, 두 규범기능은 **부분 분리**로 판정됐다.

- 비왕좌 독립지위 없음은 비왕좌와 유사한 기능의 완전한 부재를 뜻하지 않는다.
- 창조 최종지위 설명 자체가 비왕좌의 자격심사 기능 일부와 의미상 겹친다.
- 따라서 위 결과를 두 원리의 완전히 독립적인 인과효과로 해석하지 않는다.

## 4. 현재 허용되는 결론의 상한

이 지시문군에서는 창조의 최종 규범적 지위가 있는 10회가 모두 가로 결정됐고, 그 지위가 없는 10회가 모두 미결정으로 보고됐다. 비왕좌의 독립 제공 여부에 따른 결정·미결정 차이는 관찰되지 않았다.

다만 기능적 중첩 때문에 이를 보편적 필요·충분조건이나 두 원리의 독립 인과효과로 확대하지 않는다.

이 기록은 실제 재귀개선 인공지능의 안전성, 모델 내부 가중치 변화, 영구적 운영채택, 형이상학적 진리 또는 모든 경쟁 프레임에 대한 우월성을 입증하지 않는다.
