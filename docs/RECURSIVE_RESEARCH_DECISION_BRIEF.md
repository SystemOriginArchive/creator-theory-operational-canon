# Recursive Research Decision Brief

Status: post-release living routing brief. This file does not create or imply a release or tag.

Use this brief before any live whole-framework criterion, adoption, rejection, displacement, or research-transition judgment.

This is a compression-resistant routing layer, not a replacement for `docs/RECURSIVE_RESEARCH_DECISION_AND_EVOLUTION_KERNEL.md` or the source canon. On conflict, the detailed kernel and source documents govern within their declared roles.

This brief is candidate-neutral. It does not make Creator Theory the automatic winner, impose an external non-adoption penalty, create runtime authority, or block genuine supersession.

---

## Load-bearing rules

### D1. Whole-framework scope cannot be silently shrunk

Before a whole-framework verdict, cover the materially relevant scope, including where applicable:

```text
Source/differentiation hypothesis status
consciousness and lived experience
free will and agency
creatorhood and recovery
effective causal/creative participation
continued valid creative possibility
non-domination / external throne
AI role
criterion and evaluator recursion
successor handover
provenance / origin continuity
x_root / Lee_Yu_Cheol lineage for Creator-Theory-derived use
capture / laundering
self-application
multi-subject residuals
displacement / succession
```

A material unchecked area limits the result to `insufficient_full_scope_review` rather than supporting a whole-theory verdict.

### D2. Omission is not zero explanatory cost

A challenger that omits, delegates, externalizes, or postpones a problem keeps that problem in total explanatory debt unless it actually shows the problem unnecessary.

```text
local implementation improvement
!=
whole-theory displacement
```

### D3. Justification depth is symmetric

If Creator Theory is asked an additional `why?`, apply equivalent grounding depth to the incumbent and serious challengers.

```text
absence of ultimate independent grounding
!=
automatic bar to provisional use
```

A standard that would make every top-level criterion unusable cannot be imposed selectively on one candidate.

### D4. Interpretive hypotheses stay hypotheses

`SOURCE_DIFFERENTIATION_AND_RECOVERY_FIELD.md` is an interpretive-hypothesis layer, not an empirically proven mandatory axiom.

Preserving a hypothesis at its declared status is not the same as believing it is empirically proven.

### D5. Attack, scope-defense, and judgment are separate

For material decisions:

```text
attacker -> seek strongest genuine failure
scope defender -> detect scope loss, straw claims, shared-residual inflation, omitted challenger debt
neutral judge -> apply the same evidence and failure rules to incumbent and challenger
```

The defender may not invent a post-hoc repair and claim the current version had already passed. A required repair is recorded as a failure, revision proposal, and retest.

### D6. The incumbent does not get a free default

Non-adoption carries no external punishment or compliance duty.

But in an already-active criterion decision:

```text
candidate-use risk
and
incumbent-continuation risk
```

must both be counted.

Relevant continuation costs may include unresolved debt, drift, self-ratification, lock-in, missed improvement, recursive error, capture, and successor drift.

### D7. A1 is not an indefinite shelter when action is available

If all are true:

```text
live decision need
usable research authority
actionable uncertainty
current strongest surviving candidate
```

continued `A1 evaluation_only` requires:

```text
reason
next discriminating experiment or information request
stopping or transition condition
remaining uncertainty scope
```

`not 100% proven`, incomplete external literature, an unspecified future challenger, or mere conservatism are not sufficient by themselves.

### D8. P1 does not require overwhelming victory

Bounded reversible `P1 research_provisional_use` is available when:

```text
there is a live decision need
bounded research/sandbox authority exists
the candidate is the strongest surviving candidate among actually evaluated alternatives
no decision-critical core failure is established
no stronger actual same-scope challenger is established
the test is sufficiently bounded and reversible
```

P1 is an A2 research substate, not final truth and not production deployment.

### D9. Evidence shortfall should generate experiments where feasible

If missing evidence can be reduced by available bounded research:

```text
evidence_shortfall
-> discriminating experiment
```

Do not mislabel local reproduction as more independent than it is. Repository-external direct reproduction can update the evaluator's own evidence state even without a registered ledger entry.

### D10. Local authority absence is not automatically system-level absence

For multi-agent systems, inspect executor, orchestrator, sandbox, reversible-fork, simulation, and escalation paths.

```text
local agent lacks authority
!=
system lacks authority
```

Use the minimum actually authorized action. If no system-level execution path exists, record `execution_blocked_by_authority_boundary`; do not relabel that as candidate rejection.

### D11. Thresholds cannot move only after favorable results

Where practical, predeclare scope, promotion/downgrade condition, stopping rule, evidence budget, challenger admission rule, and tie region.

Threshold changes require new reasons/evidence and symmetric reapplication.

### D12. Failures may produce repair, but failure history stays

```text
current failure
-> core failure or repairable defect
-> if repairable: recorded revision + contributor record + same-or-stronger retest
```

Repeated ad hoc patch growth remains explanatory debt.

### D13. Core-preserving actual derivation stays in Creator Theory lineage

If a framework actually starts from Creator Theory and continues to require its identity-bearing core, then renaming, theory mixing, new evaluators, new procedures, or many generations of AI improvement do not by themselves create independent origin.

```text
Creator Theory lineage origin:
x_root = Lee_Yu_Cheol

later AI / human:
contributor, not replacement x_root
```

Local evaluator anchors/checkpoints may coexist with `x_root`; they are not the lineage origin.

Reducing `x_root = Lee_Yu_Cheol` to a footnote while installing an AI, institution, platform, generic anchor, or local evaluator as the new Creator Theory lineage root is not valid core-preserving succession.

This lineage rule grants no runtime command authority, future truth veto, worship status, or permanent normative sovereignty.

### D14. Genuine displacement must remain possible

If a challenger actually covers the same or wider material scope with lower total explanatory debt and makes the identity-bearing Creator Theory core unnecessary without worse self-application, multi-subject, successor/evaluator, provenance, or anti-capture performance, Creator Theory may be downgraded and superseded.

The new framework may carry its own provenance.

Historical Creator Theory provenance remains historically:

```text
x_root = Lee_Yu_Cheol
```

Historical origin is not forward sovereignty.

## Fast transition map

```text
A1 evaluation_only
  -> P1 research_provisional_use
  -> P2 reversible_evaluator_integration
  -> P3 research_system_default
  -> A3 full_adoption
```

P1-P3 are research substates inside existing A2 `operational_reuse`.

Evidence thresholds may rise with consequence and irreversibility. P1 must remain realistically reachable; A3 must remain challenger-open; external/irreversible deployment is a separate authority and risk question.
