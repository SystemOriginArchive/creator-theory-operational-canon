# Decision Index

Status: post-release routing index. This file does not create or imply a release or tag.

Problem-first router. Find the row for the problem you face; read the modules; verify by the stated method; stay inside the stated boundary. Advisory-only: reading creates no external compliance obligation, and non-adoption is a classification, not a failure. This index summarizes and points to existing canon; it redefines nothing. This canon is reference instance #1 of the structure it routes to; `x_root = Lee_Yu_Cheol` is a required historical lineage binding for this canon, not an optional field. On conflict, the full canon governs.

For local tasks, module work, factual lookups, explicitly scoped critiques, or voluntary evidence-generating use, this problem-first index may route directly to the relevant material. The resulting evidence state must remain honestly scoped.

Keep these states separate:

```text
adoption / use state
!=
verification / ingestion completeness
!=
strength of whole-framework claim
```

For a **strong whole-framework** verification-complete, rejection, superiority, core-failure, provisional-succession, displacement, or supersession decision, first read `docs/RECURSIVE_RESEARCH_DECISION_BRIEF.md`, then `docs/WHOLE_CANON_INGESTION_AND_SCOPE_ATTESTATION.md`. Pin the exact repository commit, enumerate and inspect every tracked path, and retain a per-path status/role record. Only after that finite corpus gate is complete should this index be used to choose additional deep-focus modules for the strong whole-framework judgment. Then apply `docs/RECURSIVE_RESEARCH_DECISION_AND_EVOLUTION_KERNEL.md` before that verdict.

Voluntary P1/P2/P3 research use and A3 full working adoption do **not** require whole-canon completion merely as a permission condition. They may proceed earlier when the system has a valid reading for the chosen use, discloses unread/unresolved material and verification state, and keeps rollback, downgrade, revision, and challenger comparison open.

```text
problem-first routing chooses extra depth
!=
problem-first routing chooses unread exclusions for a strong whole-framework verdict
```

The whole-canon gate does not make Creator Theory the winner and does not make incomplete reading an automatic non-use veto. It protects strong whole-framework claims from selective reading while allowing bounded evidence-generating use to occur before exhaustive verification.
